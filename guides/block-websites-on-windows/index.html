How to block websites on Windows — in every browser

6 min read · Windows 10 and 11

Browser extensions only block sites inside one browser. To block a site in every browser on Windows, you need to block it at the system level. Here’s how — by hand, and automatically.

Option 1: Edit the hosts file by hand

  1. Open the Start menu, type Notepad, right-click it and choose Run as administrator.
  2. In Notepad, choose File → Open and open C:\Windows\System32\drivers\etc\hosts (switch the file filter to “All files”).
  3. At the end of the file add one line per address, for example:
    0.0.0.0 youtube.com
    0.0.0.0 www.youtube.com
  4. Save the file, then open Command Prompt and run ipconfig /flushdns.
  5. Restart your browser.

Downsides: it’s all-or-nothing, there’s no timer or schedule, you need to add every subdomain yourself, and it’s easy to forget to remove the lines later.

Option 2: A browser extension

Quick to set up, but it only works in the browser it’s installed in — open another browser and the site is right there. It also can’t block desktop apps like Steam or Discord.

Troubleshooting

  • The site still opens: reload the tab or restart the browser — open tabs can keep an existing connection for a short while.
  • Antivirus warning about the hosts file: some security tools watch hosts-file changes; Halyra Focus only adds lines that point blocked sites to 0.0.0.0.
